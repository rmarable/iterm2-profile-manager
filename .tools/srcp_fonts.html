Fixed-width fonts for iTerm2 Profile Manager

Each card shows whether the font is in the random font pool, whether it's installed on this Mac, and where it comes from. Homebrew fonts aren't installed by default; the one exception is MesloLGS Nerd Font, which setup.sh installs with Homebrew, if Homebrew is there, because Oh My Zsh prompts need it. Copy a card's command into a terminal to add that font.

  • A red Not drawn badge means the browser used a fallback font instead. Safari won't use fonts you installed yourself, so this page carries copies of most of them (very large files are left out, and fonts in the pool come first). Keep the page to yourself: some, such as SF Mono, are licensed by Apple.
  • Fonts that aren't installed are previewed from web copies (Fontsource on jsDelivr; Hack and 0xProto from their own packages), Latin characters only. The installed fonts have the full character set.
  • iTerm2 keeps ligatures off by default, so this page does too; use the button to see them.
